# DONSOR-WALLET
專屬於 Rosie 與 Wella 的共同記帳應用程式。  
A shared expense tracker crafted specifically for Rosie and Wella.

專案緣起  
為了清楚統計我們日常生活中彼此代墊的所有費用與共同支出，在AI時代下，我們透過Vibe Coding迅速打造出這款專屬App，不僅完美契合我們的需求，也省下了每年NT$899的記帳軟體訂閱費用！

主要功能  
● 共同支出記錄：快速記錄日常各項共同花費與明細。  
● 代墊費用拆帳：自動統計代付金額，一鍵結算更省心。  
● 客製化體驗：量身打造最直覺、符合我們兩人習慣的記帳流程。  

About the Project  
Built to easily track shared expenses and reimbursements in our daily lives. In the age of AI, we developed this custom app using Vibe Coding—tailoring it to our exact needs while saving an annual subscription fee of NT$ 899.

Features  
● Shared Expense Tracking: Log and categorize shared daily spending effortlessly.  
● Split & Reimbursement Management: Automatically calculate who paid for what and settle balances with ease.  
● Customized Experience: Designed specifically around our shared financial habits and workflow.
